# e-plantShopping

## Paradise Nursery

Paradise Nursery is a React-based online plant shopping application. The application allows users to browse different categories of plants, add plants to a shopping cart, update quantities, remove items, and view the total cost of their cart.

## Project Description

The Paradise Nursery application was created as a shopping cart project using React and Redux. Users can explore a collection of plants organized into different categories and add their favorite plants to the cart.

The application provides a simple and interactive shopping experience where cart information is updated dynamically as users add, remove, or change the quantity of products.

## Features

- Landing page for Paradise Nursery
- Get Started button for entering the plant store
- Navigation between the plant collection and shopping cart
- Five plant categories:
  - Air Purifying Plants
  - Aromatic Fragrant Plants
  - Insect Repellent Plants
  - Medicinal Plants
  - Low Maintenance Plants
- Plant images, names, descriptions, and prices
- Add to Cart functionality
- Add to Cart button changes to "Added to Cart"
- Shopping cart quantity indicator
- Increase and decrease item quantities
- Remove items from the cart
- Individual item totals
- Overall cart total
- Continue Shopping functionality
- Checkout button
- Redux state management for the shopping cart
